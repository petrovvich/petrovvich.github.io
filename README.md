# Aleksandr Romaniuk, resume

Static resume site in English, Russian and Spanish: https://petrovvich.github.io

- All text lives in `content.js`; `app.js` only renders it. Bump `UPDATED` there when you revise the content.
- Open `index.html` in a browser to preview.
- After editing the content, run `tools/build.sh` to regenerate `resume-{en,ru,es}.pdf`, `og.png` (link preview) and `apple-touch-icon.png`. It needs Google Chrome or Chromium.
